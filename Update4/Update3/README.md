# LexaOS Update-Paket – Update3

## Inhalt

Dieses Update bringt die **Taskleisten-Farbe** als neue Funktion und behebt Schriftfehler im Lexa Store.

### Neue Funktion: Taskleisten-Farbe 🎨

In **Einstellungen → Taskleiste** kann jetzt die Farbe der Taskleiste geändert werden:

- **10 vordefinierte Farben**: Standard (Dunkel), Blau, Grün, Rot, Orange, Lila, Hellblau, Pink, Weiß, Schwarz
- **Eigene Farbe** per Farbwähler (Color Picker)
- Die Farbe wird sofort angewendet auf:
  - Taskleiste
  - Startmenü
  - Schnelleinstellungen
  - Benachrichtigungszentrum
- Die Auswahl wird gespeichert und beim nächsten Start wiederhergestellt

### Lexa Store – Schriftfehler behoben

- Mojibake in Kommentaren (`?"`, `"-ffnen"`, `?'`) repariert
- Sterne-Bewertung (`★☆`) korrekt dargestellt
- Ternary-Operatoren (`? :`) repariert

## Installation

1. `Update3`-Ordner auf GitHub hochladen nach `Max762342/LexaUpdates`
2. LexaOS → Einstellungen → Updates
3. „Update herunterladen" drücken
