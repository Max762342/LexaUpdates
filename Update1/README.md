# LexaOS Update-Paket – Update1

## Inhalt

Dieses Update fügt die neue App **Systemsteuerung** hinzu.

### Neue App: Systemsteuerung 🎛️

Die Systemsteuerung bietet umfassende Geräte-Einstellungen in 9 Kategorien:

| Kategorie | Beschreibung |
|-----------|-------------|
| 🖥️ Anzeige & Bildschirm | Helligkeit, Nachtlicht, Bildschirmschoner, Auto-Sperren |
| 🔊 Ton & Audio | Lautstärke, Systemtöne, Mikrofon, Wiedergabe-Gerät |
| 📶 Netzwerk & Internet | WLAN, Hotspot, VPN, Datensparmodus |
| 🔋 Akku & Energie | Energiesparmodus, Energie-Modi, Standby |
| 🔒 Datenschutz | Kamera, Mikrofon, Standort, Werbung, Diagnosedaten, Verlauf löschen |
| 🖨️ Geräte & Zubehör | Bluetooth, Drucker, USB |
| ♿ Barrierefreiheit | Hoher Kontrast, Farbfilter (Farbfehlsichtigkeit), Textgröße, Sprachausgabe |
| 🕒 Datum & Uhrzeit | Automatische Zeit, Zeitzone, Anzeige-Format |
| ℹ️ System-Info | Geräte-Informationen, Software, Wartung |

## Installation

1. Diesen `Update1`-Ordner auf GitHub hochladen nach `Max762342/LexaUpdates`
2. LexaOS öffnen → Einstellungen → Updates
3. Auf „Update herunterladen“ klicken
4. Die Systemsteuerung erscheint im Startmenü und auf dem Desktop

## Dateien

- `update.json` – Update-Metadaten & Systemdaten
- `systemcontrol.js` – Die neue App (wird ins LexaFS abgelegt)
